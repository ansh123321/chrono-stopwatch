# ⏱️ CHRONO — Premium Stopwatch

A modern, responsive stopwatch built with HTML, CSS, and JavaScript.
Designed with a premium dark interface, precision timing, and convenient keyboard shortcuts.

## 🌐 Live Demo

https://ansh123321.github.io/chrono-stopwatch/

## ✨ Features

- Start, pause, resume, and reset controls
- Lap tracking with split and total times
- Best-lap and slowest-lap indicators
- Keyboard shortcuts for quick operation
- Responsive layout for different screen sizes
- Modern dark theme with violet and cyan accents
- Accessible controls and interactive status indicators

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts

## ⌨️ Keyboard Shortcuts

| Key | Action |
|---|---|
| Space | Start or pause the stopwatch |
| R | Reset the stopwatch |
| L | Record a lap |
